# GODSEYE v4.15 — Calendar Date Double-Click

- Double-click any calendar day to open the Create Appointment modal for that date.
- Works on past dates, current dates, future dates, and outside-month dates shown in the six-week month grid.
- A selected date opens with a default start time of 9:00 AM and a one-hour end time.
- Existing appointments remain clickable for editing.
- Double-clicking an existing event opens that event and does not also create a new appointment.
- Calendar day hover styling makes interactive dates easier to discover in light and dark mode.
- Dark-mode screenshot pack refreshed to show direct date creation.
