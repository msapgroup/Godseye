GODSEYE v4.24.0

Fresh install:
  sudo ./install.sh --fresh

Upgrade an existing GODSEYE installation:
  sudo ./install.sh --upgrade

Auto-detect install vs upgrade:
  sudo ./install.sh

Includes Windows Agent 2.2.1 with system-tray status UI and approved remote-access prompt.
The installer self-reexecutes under Bash even if invoked as sh install.sh.
Upgrade mode preserves /var/lib/godseye and /etc/godseye.env and creates a pre-upgrade database backup.
