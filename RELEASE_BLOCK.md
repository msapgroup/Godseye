# GODSEYE Major Block

This release advances GODSEYE into network intelligence and correlation.

Included:
- Device-source correlation
- Offline-first MAC/OUI enrichment
- IP history foundations
- Persistent issue foundations
- Persistent topology foundations
- DHCP/Nmap/neighbor observation pathways
- Monitoring integration foundations
- Diagnostics/troubleshooting foundations
- Responsive sidebar navigation
- Raspberry Pi native installation
- No Docker dependency

The next release can add live router/AP topology and external OUI database updates without changing the device identity model.
