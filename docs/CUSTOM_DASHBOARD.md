# GODSEYE workspace guide

The original Dashboard remains available. **Dashboard → Customize dashboard** opens a separate personal workspace.

1. Select **Customize cards**, then **Add cards**. Search the catalog and select **Add**. Close the picker with **Done**, **×**, or Escape.
2. Choose Compact, Standard, Half width, Wide, or Full width from each card's size menu.
3. Drag cards to reorder them, or use the arrow buttons. **×** removes a card from your workspace.
4. Select **Save layout**. The layout is stored for your signed-in account and restored on your next login. It travels with a full server backup.
5. **Cancel** discards the current edits. **Reset** loads the default selection into the editor; save it to keep it.
6. Use **Refresh** to request current data. Cards also refresh while the workspace is visible. **← Dashboard** returns to the original view.

## Data and permissions

Inventory, findings, service checks, tickets, topology, EDR reviews, linked-site snapshots, server health, CRM, and KB cards use existing authenticated APIs and actions. Unavailable data is shown as unavailable rather than replaced with invented values. EDR coverage measures available endpoint reviews, not an overall security score. Cards honor the existing sidebar permissions; only administrators manage users and permissions. Saving a personal layout does not alter a user's role or another user's workspace.

## Maps and motion

The round Earth globe uses shaded surface artwork and a separate moving cloud layer. Select **Pause** to pause it, **Spin** to restart it, or drag the globe and use arrow keys to turn it. The world-map preview uses geographic city coordinates for Tampa, New York, London, Tokyo, São Paulo, and Sydney, with animated pulse paths and clouds. These world routes are explicitly illustrative, not inferred network-hop geolocation. **Open Network Map** shows your discovered network and its evidence. Reduced-motion preferences pause default globe motion and suppress pulse/cloud animations.
