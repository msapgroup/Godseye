# GODSEYE Feature Inventory

This release consolidates the implemented feature architecture in one place.

## Discovery
ARP, Nmap, IPv4/IPv6 neighbors, hostname/DNS helpers.

## Intelligence
MAC-first device correlation, vendor enrichment, IP history, persistent findings, topology relationships.

## Monitoring
Website, DHCP, public IP, Pi-hole, UniFi, and SNMP monitoring foundations.

## Tools
Diagnostics and Wake-on-LAN.

## Observability
Alerts, events, and Prometheus integration foundations.

## Automation
Notifications, workflows, and reports foundations.

Feature registry: `app/feature_registry.py`.
