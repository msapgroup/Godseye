# GODSEYE UI Design

The application UI has been rebuilt to closely follow the supplied GODSEYE design reference: dark left navigation, white/light workspace, blue primary actions, compact status cards, device inventory, topology map, monitoring, findings, tools, integrations, and responsive layouts.

The reference image is stored at `docs/screenshots/godseye-reference-design.png`.

The live dashboard is not a static screenshot: its device, health, findings, topology, monitoring, and activity panels are populated from GODSEYE APIs where available.
