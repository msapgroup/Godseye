# GODSEYE UI Design

The current GODSEYE UI uses a consistent dark-mode workspace with a dark left navigation, dark cards and panels, PI-HOLE-blue accents, bright high-contrast text, compact status cards, device inventory, topology map, monitoring, findings, tools, integrations, reports, and responsive layouts.

The current UI reference is stored at `docs/screenshots/godseye-dark-mode-overview.png`.

The live dashboard is not a static screenshot: its device, health, findings, topology, monitoring, and activity panels are populated from GODSEYE APIs where available.
