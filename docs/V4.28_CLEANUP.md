# GODSEYE V4.28 Clean Rebuild Audit

V4.28 was rebuilt from the uploaded GODSEYE application as a clean release rather than carrying forward the historical patch stack.

## Removed from the release

- historical root `*_RELEASE_NOTES.md` patch files;
- obsolete patch/apply scripts under `.github/scripts`;
- the legacy script-compiled Windows Agent under `windows/agent`;
- stale clone/repository-oriented installation material;
- duplicate update/deployment logic that had drifted from the main installer.

The installed application is staged from an explicit allow-list, so files left behind by an older release are not copied into the new `/opt/godseye` tree.

## Installer corrections

- fresh install and upgrade run directly from the extracted release ZIP;
- upgrade preserves `/var/lib/godseye` and `/etc/godseye.env`;
- a pre-upgrade SQLite backup is created;
- the old application tree is held for rollback until service validation succeeds;
- database migration runs from `/opt/godseye` with `PYTHONPATH=/opt/godseye`;
- the Python virtual environment is rebuilt at its final absolute path;
- `.venv` execute permissions are preserved;
- checked-in systemd unit files are the single service definitions;
- staged application updates delegate to the same installer.

## Windows Agent corrections

The permanent Windows Agent is the only endpoint agent packaged by V4.28. The server, update manifest, MSI, guided Setup EXE, source project, and future Windows build workflow use one canonical naming contract.

The bundled Windows Agent remains version 2.2.9. Its service executable and MSI are x64. The generated binaries came from the uploaded release and were not rebuilt in the Linux validation environment.

## Screenshot repair

The uploaded release contained malformed PNG data in the dark-mode screenshot pack. The affected documentation images were repaired/regenerated, and the V4.28 release validator now checks PNG signatures and chunk CRCs before installation or publication.
