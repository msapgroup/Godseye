# GODSEYE v4.10 — Header Help Pop-outs

- Hides descriptive header/subheader text on dashboard pages and section table headers.
- Adds a compact blue circular `?` beside headings when help text is available.
- Clicking `?` opens the hidden text in a focused pop-out.
- The pop-out closes with the `×` button, Escape, or clicking the overlay.
- Supports light and dark mode, using the GODSEYE/Pi-hole blue family in dark mode.
- Applies the same pattern to the standalone Network Tools page.
