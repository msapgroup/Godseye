# GODSEYE v12 — Monitoring + Findings Remediation

- Fully working Add/Edit/Delete/Run monitor controls
- Run one monitor or all monitors
- Per-monitor latest status and response time
- Automatic findings after repeated service failures
- Offline findings from scanner transitions
- IP-change findings
- Packet-loss and DNS findings after repeated diagnostics
- Suggested Fix / Recheck / Resolve controls
- Automatic resolution when monitored conditions recover
- Audit logging for finding rechecks/resolution

Suggested Fix is advisory; GODSEYE does not make destructive network changes automatically.
