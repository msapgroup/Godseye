# GODSEYE v3.0.0 — Modal Forms & Monitoring UI

- Add Device now opens as a centered modal overlay instead of rendering at the bottom of the page.
- Add/Edit Monitor now opens as a centered modal overlay with clearer fields and help text.
- Both modals close with Cancel, the X button, outside-click, or Escape.
- Background scrolling is locked while either modal is open.
- Monitoring now includes Total, Healthy, Needs Attention, and Disabled summary cards.
- Monitoring table styling and empty state were cleaned up for readability.
