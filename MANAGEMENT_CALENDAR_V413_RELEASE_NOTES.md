# GODSEYE v4.13 — Management Calendar

- Adds Calendar under the Management sidebar.
- Adds a Google Calendar-inspired dark-mode month view with Today, previous/next month, upcoming appointments, and color-coded events.
- Adds administrator create/edit/delete appointment modal with an `×` close control.
- Stores local calendar events in SQLite and audits create/update/delete actions.
- Adds Google Calendar and Microsoft 365 / Outlook calendar integration options using encrypted private ICS subscription URLs.
- Imported external appointments are read-only inside GODSEYE; local appointments remain editable.
- Adds on-demand external calendar synchronization with bounded feed size and event count.
- Adds Calendar to the current dark-mode screenshot pack and refreshes the overview montage.
