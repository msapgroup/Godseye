# GODSEYE v3.9 — Per-Device Traffic Collection UI Refresh

The Reports traffic collector has been redesigned into a cleaner source-selection workflow.

- Four visual source cards replace the exposed mode dropdown.
- New 24-hour summary cards show active source, download, upload, and measured device count.
- Source configuration and source requirements are separated into clear cards.
- Collection status is presented as a dedicated state chip.
- Top-device usage is easier to scan with source/confidence chips and formatted usage.
- Responsive layouts cover desktop, tablet, and mobile.
- Backend traffic collection behavior is unchanged from v3.8.
