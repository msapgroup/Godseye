# GODSEYE v4.2 — Dark Mode Completion + Report Cards + Dark Login

This release fixes the remaining light surfaces by placing a final high-specificity dark-theme layer at the end of the dashboard stylesheet.

Key changes:
- Device Discovery / Network Tools, topology, monitoring, analytics, device intelligence, report, modal, traffic, map, and control cards stay dark before hover.
- Dark-mode text is brighter: primary text is near-white and secondary text has stronger contrast.
- Login/authentication cards, labels, inputs, buttons, and footer now honor dark mode.
- Reports now exposes all eight report types as individual selectable cards instead of a hidden visual concept behind one dropdown.
- Selected report cards show a blue state and checkmark; Generate Selected Report runs the chosen report.
