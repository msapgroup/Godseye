# Security Policy

## Supported versions

Please use the latest published GODSEYE server release and the latest applicable Windows Agent release. Security fixes are developed for the current release; older versions should be upgraded when a fix is available.

## Report a vulnerability

If you believe you have found a security vulnerability in GODSEYE or the Windows Agent, please report it privately to **[info@msapgroupllc.com](mailto:info@msapgroupllc.com)** with the subject **GODSEYE security report**. Do not open a public issue or discussion with vulnerability details.

Please include:

- The affected version and component, and the operating system.
- A description of the issue and its potential impact.
- Steps to reproduce it, preferably using a test environment.
- Any relevant screenshots or sanitized logs.

Do not include passwords, access tokens, encryption keys, customer data, or production backups in your report. MSAP Group will review reports and work with the reporter on appropriate next steps and coordinated disclosure. Response and fix times depend on the issue and available information.

Please test only systems you own or have permission to assess, and avoid actions that disrupt service or access other people's data.

## Security updates

Updates and release notes are published in the [GODSEYE repository](https://github.com/msapgroup/Godseye/releases). Administrators should review updates, maintain current backups, and keep deployments on a trusted network or VPN.
